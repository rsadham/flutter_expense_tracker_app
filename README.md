
# Flutter Expense Manager

A personal Expense Manager application developed using Flutter.

## Features
- Add Income transactions
- Add Expense transactions
- View transaction history
- SQLite local database
- BLoC state management
- Clean Architecture

## Tech Stack
- Flutter & Dart
- BLoC
- Clean Architecture
- SQLite (sqflite)

## Project Structure
- core
- data
- domain
- presentation

## Getting Started

1. Clone the repository.
2. Run flutter pub get.
3. Run flutter run.
